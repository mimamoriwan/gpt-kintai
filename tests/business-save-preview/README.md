# 会社の取り組み・保存ボタン検証画面

リポジトリのルートで次を実行します。

```sh
npx vite --config tests/business-save-preview/vite.config.ts
```

`http://127.0.0.1:5191/tests/business-save-preview/` を開きます。

- 実際の `BusinessPage`、日本語・簡体字切替、共通 CSS と本番と同じレイアウトの親要素を使います。
- 本番と同じく `.page-content` の直下に `BusinessPage` を配置し、余分な `.page` ラッパーは付けません。実際の `AppHeader` でヘッダー高さの CSS 変数も計測します。
- スマートフォン幅では実際の `.bottom-nav` の固定配置が有効です。
- 「取り組みを追加」、既存項目の「取り組みを編集」、節目の追加、「テーマを管理」、「共有メンバー設定」の保存を試せます。
- 8 件の節目を持つ既存の架空取り組みがあり、長い編集画面をすぐ確認できます。
- 全 API はメモリー内の架空データを使用します。保存後は通常の成功メッセージが表示され、一覧・詳細・再編集にも反映されます。再読み込みで初期状態に戻ります。
- 本番 API と認証の実装は読み込みません。CSP でも外部ネットワークを禁止しています。翻訳は原文を返す検証用実装です。
- このディレクトリーは通常のアプリビルドのエントリーポイントではありません。
