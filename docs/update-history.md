# 更新情報の記録

サイドバーの「更新情報」を選択したときだけ、更新日時・修正箇所・修正内容・できるようになったことを表示します。ホームへの常時表示や自動ポップアップは追加しません。アプリを新版に切り替える既存の更新案内とは別の機能です。

## 今後の変更時

1. 利用者向けの変更を実装したら、同じ変更内で `src/data/updates.ts` の `updates` に1件追記します。ChatGPT Workなどで修正する場合も同じです。Git履歴や会話から自動生成する機能ではありません。
2. 重複しない `id` と、実際の変更記録日時をタイムゾーン付きISO形式で指定します。`kind` は新機能 `feature`、改善 `improvement`、不具合修正 `fix` から選びます。
3. `ja` と `zh-CN` の両方に、短い題名、修正箇所、具体的な変更、利用者ができることを記載します。機密、個人名、メールアドレス、パスワード、個人の業務内容は書きません。
4. 更新情報画面の表示・検索・両言語を確認し、型検査と該当テストを実行します。表示順は画面側で `updatedAt` の新しい順に並べます。

```ts
{
  id: "実際の日付-変更を識別する名前",
  updatedAt: "実際の変更記録日時（例: YYYY-MM-DDTHH:mm:ss+09:00）",
  kind: "improvement",
  content: {
    ja: {
      title: "検索しやすく改善",
      areas: ["対象画面"],
      changes: ["具体的に変更した内容。"],
      benefits: ["利用者ができるようになったこと。"],
    },
    "zh-CN": {
      title: "改进搜索体验",
      areas: ["目标画面"],
      changes: ["具体修改内容。"],
      benefits: ["用户现在可以做的事情。"],
    },
  },
}
```

上記の日時・IDは説明用です。そのままコピーせず、実際の値へ置き換えます。

## 日時と公開状態

`updatedAt` は実際の変更記録日時です。公開日時や本番反映の成功を保証しません。今回追加した「更新情報をメニューから確認」は2026年9月17日10:24:18（日本時間）の変更記録で、この記録を作成した時点では本番未公開です。将来の公開日時を先取りして記録しません。

過去5件は確認済みの本番公開記録を根拠に、その公開日時を設定しました。今後も公開時刻を記録する場合は、公開成功と実際の時刻を確認した後にデータを修正し、表示データを含む画面を再反映する必要があります。未公開の作業を公開済みと記載しないでください。
