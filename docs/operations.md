# 運用手順

## 毎日の運用

1. 従業員は勤務形態を選択し、「始業」を押します。
2. 業務終了時に日報を入力して提出します。中国語本文は原文を保持し、日本語版を自動生成します。
3. 「終業」を押します。表示時間は休憩を控除していない経過時間です。
4. 打刻忘れや通信不良があった場合は、実時刻と理由を入力して訂正します。
5. 管理担当者は未提出・未退勤・再確認が必要な記録を確認します。

## 定期作業

- 毎週: 管理画面から対象月のバックアップを出力し、会社管理の保管領域へ保存します。
- 毎月: Firebase、Storage、Functions、OpenAIの利用量と請求額を確認します。
- 退職・長期停止時: アカウントを削除せず無効化し、既存記録を保持します。
- 記録は最低5年間保持し、自動削除しません。

## 修正記録

提出後の修正では旧内容、修正者、日時、理由が履歴に残ります。管理担当者は本人の原文を上書きせず、内容を確認済みにします。修正後は再確認が必要です。

## 在留期間更新前

このシステムは勤務実態の説明に役立つ日常記録を蓄積しますが、更新許可や資料採用を保証しません。申請前に、行政書士の助言、出入国在留管理庁の最新案内、雇用契約・就業規則に関する社労士の確認を改めて行ってください。
