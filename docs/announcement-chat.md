# お知らせの個別チャット

2026年9月22日実装。本番未反映。

## 動作

- 各お知らせの「返信・チャット」で、発信者と各受信者が回数制限なく会話する。
- 複数宛先では個別の会話とし、発信者が相手を選択する。他の受信者には公開しない。
- 確認・対応完了と送信は独立。未確認・対応中・完了後に送信できる。取消後は閲覧のみ。
- 1通2000文字。送信者名・サーバー日時・本文を保持。以前の完了コメントも履歴に表示する。
- 最新50件を購読し、過去の返信は50件ずつ追加表示。読み込んだ履歴は新着で消さない。
- 送信失敗時に入力と送信IDを保持する。同じIDの再送をトランザクションで重複排除する。
- チャットを開いている間は新着を自動反映。外部通知、返信の自動翻訳、返信用添付、下書きの永続化は含まない。

## 保存・権限

保存先は `presidentInstructions/{instructionId}/conversations/{recipientId}/messages/{messageId}`。本文を親ドキュメントの配列に追加しないため、返信数によって親の容量上限に達しない。

新しいCallable `replyToPresidentInstruction` が本人の有効性・宛先・デモ範囲・取消状態をトランザクション内で検証し、メッセージと監査記録を同時作成する。クライアントの直接作成・変更・削除は禁止。読み取りは親の発信者と、その会話の受信者に限定する。
